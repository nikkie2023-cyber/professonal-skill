# 爆款拆解助手（Chrome 扩展）

这个扩展用于把当前打开的抖音或小红书视频页面发送到本地工作台。它会先尝试读取当前页面播放器中可访问的视频并上传；如果平台使用受保护或分片播放器，则退回保存链接并让工作台提示用户上传视频。它只使用当前登录页面的正常播放权限，不读取密码、Cookie，也不会自动登录平台。

## 本地安装

1. 先启动工作台，确认浏览器能打开 `http://127.0.0.1:8000/`。
2. Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本文件夹 `browser_extension`。
6. 在抖音或小红书打开想研究的视频页面，点击浏览器工具栏里的“爆款拆解助手”。
7. 点击“发送到拆解系统”，扩展会保存链接并打开工作台。

## 重要说明

平台分享页通常是网页链接，不一定是可以直接下载的 MP4 直链。扩展负责“保存参考链接”，真正分析时如果平台限制读取，工作台会提示上传视频文件。这样不会把平台网页误当成视频处理。

## 分享给别人

如果工作台部署到了 HTTPS 公网地址，用户在插件弹窗里把“工作台地址”改成你的公网地址即可。分享插件时只打包本文件夹，不要把项目根目录的 `.env` 或任何 API Key 放进插件。
